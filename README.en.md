# Foreign Company Radar

Foreign Company Radar is a job and benefits intelligence site for people in China who want to find real opportunities at multinational companies. It is designed to help users discover companies and jobs by industry, city, benefits, and official career sources.

Live site: [https://foreign-company-searcher.pages.dev](https://foreign-company-searcher.pages.dev)

![Foreign Company Radar homepage](docs/assets/homepage.png)

## Key Features

- Foreign company directory: companies are organized by industry, niche sector, country or region, and major China cities.
- Search and filters: search by company, city, role direction, or benefit keyword.
- High-value benefit tags: social insurance, commercial insurance, extra benefits, employee stock, hybrid work, employee discounts, and more.
- Featured recommendation: highlights companies and openings worth checking today.
- Official job feed: SAP China jobs are currently integrated as the first proof of concept.
- Company details: click a company card to view role directions, benefit tags, career links, and notes.
- Product docs: product planning, software design, and the SAP crawler plan are stored in `docs/`.

## Current Data Sources

- Company directory: `foreign_companies_by_industry.csv`
- Frontend company data: `public/foreign_companies_by_industry.csv`
- SAP job feed: `public/jobs/sap-china.json`
- Raw crawler output: `data/jobs/sap-china.json`

## Run Locally

```bash
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5173/
```

## Update SAP Jobs

```bash
npm run scrape:sap
cp data/jobs/sap-china.json public/jobs/sap-china.json
npm run build
```

The crawler fetches SAP Careers search results for China and extracts job title, city, source URL, and scrape time.

## Build

```bash
npm run build
```

The production build is generated in `dist/`.

## Deploy

This project is currently deployed on Cloudflare Pages.

```bash
npm run build
npx wrangler pages deploy dist --project-name foreign-company-searcher --branch main
```

## Product Direction

Foreign Company Radar is not meant to be just another general job board. The long-term direction is to build a focused intelligence layer for multinational-company jobs in China: official job sources, benefit credibility, outsourcing-risk detection, and niche industry maps.

Planned extensions include:

- More official career-site crawlers.
- Employment type and outsourcing-risk detection.
- Benefit evidence and confidence levels.
- Industry topic pages, such as pet care, furniture, semiconductor equipment, testing and certification, and flavors and fragrances.
- Job subscriptions and update alerts.
