# 外企雷达 · Waiqida

> 网站地址：**[https://waiqida.cn](https://waiqida.cn)**

一个专为国内求职者打造的外企信息导航平台。我们手动核验了 283 家在华外资企业的官方招聘入口，帮你省去逐个搜索的时间，直接找到靠谱的投递渠道。

---

## 为什么做这个

在中国找外企工作，最麻烦的不是简历，而是**根本不知道哪些外企在招、去哪里投**。

大多数外企不在国内主流招聘平台上活跃，甚至没有中文官网。很多求职者刷了一圈 Boss 直聘和智联招聘，发现外企岗位要么是外包，要么是中介代发，根本找不到官方渠道。

外企雷达的初心很简单：**把外企的官方招聘入口找出来，整理好，让你一眼就能找到正确的地方投递。**

---

## 有什么功能

### 公司名单（全员免费）
- 收录 **283 家**已人工核验招聘入口的外资企业
- 按行业、城市、福利标签筛选
- 关键词搜索公司名、岗位方向、城市
- 点击公司卡片查看详情：适合岗位、福利标签、官网招聘链接

### 地区地图
- 交互式中国区域地图，点击省份/区域直接显示该地区外企名单
- 地区筛选与主列表联动，方便按城市精细查看

### AI 岗位顾问
- 输入你的专业、城市、求职方向
- AI 推荐最匹配的外企行业、岗位和公司，并给出投递关键词

### 会员专属
- AI 推荐不限次
- **导出完整 283 家公司名单**（CSV，含行业、城市、招聘链接）
- 每日更新可投岗位推送

## 本地运行

```bash
npm install
npm run dev
```

本地地址：`http://127.0.0.1:5173/`

> 本地运行时部分功能（D1 数据库、AI 顾问）需要配置 `.dev.vars`，格式参考 `.dev.vars.example`。

## 构建

```bash
npm run build
```

产物输出至 `dist/`，直接部署到 Cloudflare Pages。
